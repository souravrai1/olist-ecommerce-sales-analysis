# Brazilian E-Commerce Sales & Performance Analysis

A data analysis project using MySQL and Power BI to analyze Brazilian e-commerce sales and performance across customers, orders, products, sellers, payments, reviews, and delivery.

## Project Overview

This project uses the Brazilian Olist e-commerce dataset to analyze sales performance, customer activity, product performance, delivery operations, customer reviews, seller performance, and payment behavior.

The data was organized into a relational MySQL database and prepared for analysis using SQL views and calculated metrics. The resulting data was used to develop an interactive Power BI dashboard.

## Analysis Areas

The project covers:

- Sales and revenue performance
- Order and customer analysis
- Product and category performance
- Customer geography
- Delivery and logistics performance
- Review and rating analysis
- Seller performance
- Payment analysis

## SQL Analysis

SQL was used to:

- Create and organize relational tables for the Olist dataset
- Load and prepare the data for analysis
- Connect related datasets using JOINs
- Create analytical views
- Calculate delivery days and late-delivery status
- Identify the latest review for each order
- Calculate product volume
- Aggregate payment values and payment information
- Apply date functions, CASE statements, aggregations, and window functions

## Power BI Dashboard

The prepared data was used to develop an interactive Power BI dashboard covering:

- Executive overview
- Sales trends
- Category and product performance
- Customer geography
- Delivery and logistics
- Reviews
- Sellers
- Payments
